### 踩坑
1. **E2E 断言写了 `last_seq == base + 2` 连错两次**：`operations.seq` 是**全局 AUTOINCREMENT**，不是每账号从 1 开始；新账号首条 op 的 seq 取决于表里已有行数。断言必须按实际 seq 相对写，不能按条数推算。
2. 本地 wrangler 的 D1 是持久化的（`.wrangler/`），历史测试账号/操作会累积，基线不要假设为 0（不过 last_seq 本身按 user_id 过滤，新账号仍是 0）。
3. wrangler 未预装：`npm i --no-save wrangler`（node_modules 已 gitignore，`--no-save` 保证 package.json 不动）。启动耗时约 50s。
4. 本机 Node 的 `Array.prototype.concat` 被裁（既有约定），新代码只用 spread。
