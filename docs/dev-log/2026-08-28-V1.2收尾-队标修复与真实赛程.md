## 二、本次新增（补齐上次留下的功能缺口）

1. **CS2 真实赛程**（此前是 `nextDate()` 生成的假数据，V1.2 §12 禁止项）
   - 数据源：Liquipedia MediaWiki API（免密钥；合规三件套：gzip + 描述性 UA + 服务端缓存 5 分钟）
   - `/api/sports?type=cs2matches` 解析 ticker：约 50 场未来/进行中/刚完赛，含真队标、赛事名、Bo 赛制、比分
   - 客户端 `ensureCS2Matches()`：localStorage 缓存 + last_synced_at + 失败重试 + 同步失败横幅
   - 关注匹配按"名称键"（LP 页面标题/短名 ↔ 注册表/tsdb_id/在线搜索名）双向归一
   - **删除静态 `CS2_SCHEDULE`/`FOOTBALL_SCHEDULE`**：无缓存时显示空态/失败态，不冒充真实数据
2. **足球按关注球队拉取**（免费档"联赛下一场"只有 1 场，覆盖不了主队）
   - `/api/sports?type=matches&ids=` 增加 `eventsnext/eventslast` 按队取，去重合并
3. **CS2 搜索兜底**：TheSportsDB 搜 "NAVI" 无结果 → Liquipedia opensearch 兜底（队标取战队页 infobox 首图，重定向页自动跟随）
4. **书籍简介修复**：`book.douban.com` 详情页被反爬（302 → sec.douban.com），改走 `m.douban.com/rexxar/api/v2/book/{id}` 优先，HTML 解析留作兜底；保存入库补 `rating/translator/publish_date`
5. **电影简介**（上轮已接 rexxar，本次验证入库链路）：评分来自 Provider，禁止手填
